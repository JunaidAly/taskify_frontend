Frontend (React + TypeScript + Vite + Ant Design)

See the [project root README](../README.md) for the full feature list and API overview.

Setup
- Install dependencies: `npm install`
- Run dev server: `npm run dev` (http://localhost:5173)
- Build: `npm run build`

The app expects the API at `http://localhost:5000/api` by default. Override with a `VITE_API_URL` env var.
